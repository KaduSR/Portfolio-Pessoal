# Kadu Dev - Gold Standard Design System

Pacote criado a partir dos dois ZIPs enviados.

## Estrutura

- `00-Fonte-Design-System`: DESIGN.md original
- `01-Masters-Originais`: imagens originais preservadas
- `02-PNG-Transparente`: elementos separados com canal alfa
- `03-WEBP-Lossless-Transparente`: versões web sem perda
- `04-SVG-Embedded-Transparente`: SVGs sem vetorização
- `05-PDF-Assets`: PDFs individuais
- `06-Design-System`: tokens, preset e componentes React
- `07-Templates`: HTML e preview do e-mail
- `08-Manual-e-Mapeamento`: manual, manifesto, nomes e hashes

## Observação

Os elementos transparentes foram extraídos por máscara de pixels a partir das
imagens raster. Os originais permanecem intactos e são a referência definitiva.

# Contribuindo para o Meu Portfólio Pessoal 🚀

Primeiramente, obrigado por se interessar em contribuir! Este projeto é o meu espaço pessoal para demonstrar minhas habilidades em desenvolvimento web. Toda ajuda para torná-lo mais performático, acessível ou organizado é muito bem-vinda.

## 📋 Como posso contribuir?

### 1. Relatando Bugs

Se você encontrar algum erro visual, link quebrado ou problema de responsividade, por favor:

- Verifique se o problema já não foi relatado nas **Issues**.
- Caso não, abra uma nova Issue descrevendo o erro, o navegador utilizado e, se possível, anexe um print.

### 2. Sugerindo Melhorias

Tem alguma ideia de design ou uma tecnologia que ficaria legal no portfólio?

- Abra uma Issue com a tag `enhancement`.
- Explique como essa mudança agrega valor ao projeto.

### 3. Enviando Pull Requests

Se você quer colocar a mão na massa:

1. Faça um **Fork** do projeto.
2. Crie uma branch para sua modificação: `git checkout -b feature/minha-melhoria`.
3. Faça o **Commit** das suas alterações com mensagens claras.
4. Envie para o seu repositório remoto: `git push origin feature/minha-melhoria`.
5. Abra um **Pull Request** para a branch principal.

## 🛠️ Padrões de Desenvolvimento

Para manter o código limpo e organizado (Clean Code), seguimos algumas regras:

- **HTML:** Utilize tags semânticas (header, section, main, footer).
- **CSS:** - O projeto utiliza uma estrutura modular. Se for alterar estilos globais, use o `assets/css/global.css` ou `_variables.css`.
  - Para seções específicas, utilize os arquivos dentro de `assets/css/sections/`.
  - Mantenha o uso de **Variáveis CSS** para cores e fontes.
- **Formatação:** Este projeto utiliza o **Prettier** para padronização de código. Certifique-se de formatar seus arquivos antes do commit.

## ⚖️ Código de Conduta

Seja respeitoso e colaborativo. Este é um ambiente de aprendizado e networking.
